# Cryptographie avec MATLAB

Ce projet contient l'implémentation de plusieurs algorithmes de cryptographie avec MATLAB :

- **Diffie-Hellman** : échange de clés secrètes.
- **ElGamal** : chiffrement et déchiffrement.
- **RSA** : chiffrement et déchiffrement asymétriques.
- **powermod.m** : fonction utilisée pour calculer les puissances modulaires nécessaires aux algorithmes.

Ces programmes ont été réalisés dans le cadre des TP de cryptographie en Spécialité Réseau et Télécommunications.
